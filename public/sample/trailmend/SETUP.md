# TrailMend setup

Requires Node 20 or later. Install dependencies with `npm install`.

Copy `config.example.json` to `config.json` and set `TRAILMEND_TILE_DIR` to the
directory containing downloaded vector tiles. The default tile bundle covers
the Alps and is 850 MB unpacked.

Start the dev server with `npm run dev`; it listens on port 4173. A production
build is served by `npm run preview` on the same port. The service worker is
registered automatically and caches about 40 MB of app shell.

Elevation data ships as a 220 MB SQLite file generated by `npm run build:dem`.
Without it the elevation profile panel shows a placeholder.
